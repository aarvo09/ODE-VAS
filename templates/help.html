User Guide

Complete documentation for ODE VAS

Overview

ODE VAS (Ordinary Differential Equation Visualizer & Analyzer) is a comprehensive tool built to solve, analyze, and visualize first-order differential equations. It implements numerical methods like Euler, Improved Euler, and Runge-Kutta (RK4) to provide accurate solutions.

1. Interactive Visualizer

The core usage mode for visualizing solutions and slope fields.

How to use:

  • Select a Method: Choose from Euler, Direct Integration, Separation of Variables, Integrating Factor, or Substitution.
  • Enter the Equation:
    • For Euler/RK4: Enter f(x, y) where dy/dx = f(x, y).
    • Examples: x + y, sin(x) * y, y - x**2.
  • Set Initial Conditions: Provide x₀ and y₀ values (e.g., x=0, y=1).
  • Configure Simulation:
    • Domain End: The final x value for the simulation.
    • Evaluation Points: How many points to plot (higher = smoother graph).
    • Step Size: For Euler methods, smaller step sizes yield better accuracy.
  • Visualize: Click the "Visualize Solution" button to generate the graph.

Slope Fields:

Once a solution is plotted, you can toggle the "Direction Field" to see the vector field of the equation, helping you understand the general behavior of solutions.

2. Quick Solver

Designed for fast numerical results without the overhead of graphing. Ideal for getting data tables or checking values quickly.

Usage is identical to the Visualizer, but the output focuses on numerical data tables.

3. Advanced Analysis

A powerful mode for deep exploration of ODE behavior.

Features:

  • Parameter Variation: See how changing a constant (e.g., 'k' in k*y) affects the solution curve. Enter a parameter name and a range (min/max) to generate multiple curves.
  • Stability Analysis: Identify equilibrium points (where dy/dx = 0) and determine if they are stable (attractors) or unstable (repellers).
  • Step-Size Comparison: Compare the accuracy of a solution across different step sizes to understand global truncation error and convergence.

Supported Syntax

The website supports standard mathematical syntax using Python/SymPy style:

+ Addition - Subtraction * Multiplication / Division ** Power (e.g., x**2 for x squared) sin(x), cos(x), tan(x), exp(x), log(x), sqrt(x)
